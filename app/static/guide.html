Forecast cycle labels

These names match the ledger. Later revisions never overwrite the first call.

initial_forecast First frozen call Week-ahead target close, kept as issued.
latest_forecast Most recent revision Same target week; not a replacement of the first call.
revisions Later calls Listed on the Revision timeline tab.
resolved_actual Realized close Filled only after the target week completes. Pending is not a zero.

How To Read Ticker Detail

Use the tabs. Start with Overview (Target Close Truth), then Revision timeline, Forecast vs actual, and History. Ops stays collapsed.

  1. Pick a ticker card from Watchlist (cohort badge, projected move, status).
  2. On Overview, read Target Close Truth: initial_forecast, latest_forecast, resolved_actual.
  3. Open Revision timeline when revisions exist. The first frozen call stays highlighted.
  4. Use Forecast vs actual to overlay initial call, latest call, and realized close.
  5. Use History (Resolved Week History) for completed target weeks.
  6. Open Ops only if you need snapshot metrics or the target-close path.

Empty, stale, and failed states

Missing data is labeled Unavailable or Not resolved yet. A zero is used only when the count is truly zero (for example, no open alerts).

Stale cards show a Stale badge. Load failures appear in the banner under the header — not as charts filled with zeros.
